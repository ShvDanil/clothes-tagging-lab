# Как сдать результат

Код, тесты, безопасные результаты сравнения и заполненный [REPORT.md](../REPORT.md) находятся в ветке **`feat/clothes-tagging`**. Добавлять GitHub-логин к имени ветки не нужно.

Если у вас есть право записи в исходный репозиторий:

```bash
git switch -c feat/clothes-tagging
# Выполните работу, проверьте изменения и создайте свой коммит.
git push -u origin feat/clothes-tagging
git rev-parse HEAD
```

Если ветка уже создана при первом запуске, используйте `git switch feat/clothes-tagging`. Если права записи отсутствуют, сделайте свой fork и работайте в ветке с тем же именем; в сообщении укажите ссылку именно на вашу ветку. Pull request не обязателен. Не заменяйте чужую работу и не используйте force push.

Отправьте **организатору в личные сообщения Telegram**:

1. Видеоотчет до 4 минут — файлом или доступной ему ссылкой.
2. Ссылку на ветку решения и полный хеш проверенного коммита.

Публично размещать видео не требуется. Контакт — тот, через который вам выдали задание. Если контакта нет, уточните его при получении доступов.

## Что показать в видео

- Кратко: три подхода, качество/скорость и почему выбран один из них.
- Запуск или состояние Compose, запрос с несколькими ракурсами одного товара, объединенный ответ и одну соответствующую запись в БД.
- Один показательный нештатный сценарий и поведение сервиса.
- Тесты/CI и существенное ограничение решения.

Отчет в репозитории должен позволять воспроизвести показанное без расшифровки видео. Не записывайте ключи, настройки AWS-профиля, закрытые URL и личные данные. Данные/фотографии не добавляются в Git: используйте версии релиза и идентификаторы.
